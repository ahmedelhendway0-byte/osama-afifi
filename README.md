## شيت جوجل
الكود في `sheets/Code.gs` (Apps Script ← اتعمل له setup). فاضل بعد ما المستر يعمل الإعداد:
المستر ← الإعدادات ← البيانات ← «مفتاح شيت جوجل» ← يتحط في تاب «الإعدادات» خانة B2 ← شغّل `refresh` مرة.

## الدخول
- **المستر:** «المستر والأسيستنت» ← «مستر» ← الباسورد (بيتعمل في خطوات الإعداد أول مرة).
- **الأسيستنت:** «المستر والأسيستنت» ← «أسيستنت» ← الباسورد اللي المستر عمله من الإعدادات (6 أرقام، مختلف لكل أسيستنت).
- **الطالب / ولي الأمر:** كود الطالب + الرقم السري (4 أرقام، مختلف لكل طالب، ظاهر في ملف الطالب).

## الداتابيز
Supabase مشروع `center-system` (نفس مشروع سنتر هنداوي) — كل الجداول والدوال بتبدأ بـ `oa_` ومنفصلة تماماً.
أول مرة: **SQL Editor** ← الصق `supabase/schema.sql` كله ← **Run**. بعدها أول ما المستر يفتح الرابط بتظهرله خطوات الإعداد.
للتجربة على الجهاز من غير الداتابيز: ضيف `?local=1` للرابط.
